# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for security defects or accidental
data exposure. Do not include credentials, private gateway rows, account data,
or workspace identifiers in a public issue.

## Supported version

The latest commit on `main` is the supported version.

## Publication boundary

The repository publishes sanitized task outcomes and aggregate telemetry. It
does not publish raw prompts, model output, provider identifiers, credentials,
or workspace metadata.
